# 解构工坊 · 异构文件解析与字段抽取编排平台

面向异构文件投递、格式探测、编码归一、解析器路由、抽取模板版本、字段解析、坏行隔离、结构嗅探、嵌套展平、取值转型、单位归一、输出契约、结果投递、解析水位与重解析编排的数据采集接入平台。

这是一个前后端分离的管理平台：前端 Vue 3 + Vite + TypeScript，后端 FastAPI（Python）。
两边各自独立启动，前端 dev server 已关掉自动打开页面，启动后按终端打印的地址手工打开。

## 目录结构

```text
.
├── frontend/                 Vue 3 + Vite + TypeScript 前端
│   ├── src/views/WorkbenchView.vue|tsx  全部模块共享工作台
│   ├── src/data/modules.ts              18个业务模块配置
│   ├── src/api/              统一请求封装
│   └── vite.config.ts        dev server 配置（open: false）
├── backend/                  FastAPI（Python） 后端
│   ├── app/routers/resource.py  通用查询/导出/登记/动作接口
│   ├── app/services/<key>.py    每个模块独立领域逻辑
│   ├── app/services/base.py     共享服务骨架
│   └── app/store.py          内存数据仓库与示例数据
├── .gitignore
└── docker-compose.yml
```

## 启动

### 后端

```bash
cd backend
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
./run.sh
```

健康检查：`curl http://127.0.0.1:8004/api/health`

### 前端

```bash
cd frontend
npm ci
npm run dev
```

前端默认监听 `http://127.0.0.1:5177/`，dev server 不会自动打开浏览器，
需要自己访问。`/api` 由 vite 代理到后端 `http://127.0.0.1:8004`。

## 路径转义与转型回执

嵌套展平模块额外提供新旧点路径对照工作台：

- `dot-v1`：历史 `$.a.b` 仍表示嵌套 `a → b`，反斜杠是普通字符。
- `escape-v2`：`$.a\.b` 表示字面键 `a.b`，也支持 `$["a.b"]`。
- 路径确认保存表达式原文、版本、核准轮次、文档键、匹配位置、实际行和原值。
- 取值转型回执固定核准时的路径版本与轮次；规则回滚后领取回执会返回
  `pinned_receipt`（原待执行值）和 `approved_legacy`（已核准旧路径）两个选择。
- 转型失败写入 `row_quarantine` 与 `cast_isolation_ledger`，其中保存文档键和可恢复输入快照。

开箱场景录入 `{"a": {"b": 7}, "a.b": 9}`：旧作业的 7 已完成，新路径的 9 有受理回执
`CR-NEW-AB-9` 且尚未执行。页面位于“嵌套展平”和“取值转型”，也可调用
`POST /api/path-workbench/scenario` 幂等准备数据。

## 约定

- 全部模块共享`frontend/src/views/WorkbenchView.vue|tsx`和一套资源路由。
- 每个模块仍保留独立`backend/app/services/<模块>.py`；纯前端保留
  `frontend/src/domain/<模块>.ts`，用于承载真实业务差异并维持36题位容量。
- 列表接口统一返回 `{ items, total, page, size }`，动作接口统一返回 `{ ok, message }`。
- 状态流转只允许在 `app/services` 里改，路由层不做业务判断。
